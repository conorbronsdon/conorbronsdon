## What I'm building

| | Project | What it does |
| --- | --- | --- |
| Context & memory | [agent-context-os](https://github.com/conorbronsdon/agent-context-os) | Keep identity, projects, decisions and session handoffs in reviewable Markdown, shared across Claude Code, Codex and other coding agents. Backed by Git. |
| | [agent-memory-kit](https://github.com/conorbronsdon/agent-memory-kit) | A read-only curator that finds rot and contradictions in agent memory and proposes evidence-cited diffs you review. |
| Check & prove | [ssot-check](https://github.com/conorbronsdon/ssot-check) | Find facts hand-copied across docs that have drifted from their one canonical home. |
| | [repo-audit](https://github.com/conorbronsdon/repo-audit) | For every claim that something is blocked or guaranteed, find the mechanism and grade it Enforced, Advisory or Guidance. |
| Write & publish | [avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing) | Audit and rewrite AI writing patterns. Also a [Chrome extension](https://chromewebstore.google.com/detail/avoid-ai-writing/blgifnkgdfbihjjclpddmjlnidbdihhl) and an [MCP server](https://github.com/conorbronsdon/avoid-ai-writing-mcp). |
| | [substack-mcp](https://github.com/conorbronsdon/substack-mcp) | Work on Substack drafts, Notes and analytics from an agent. |

More at [conorbronsdon.com/builds](https://conorbronsdon.com/builds?utm_source=github&utm_medium=referral&utm_campaign=repo-readme&utm_content=profile-readme): MCP servers ([gws-mcp-server](https://github.com/conorbronsdon/gws-mcp-server) and the podcast servers), agent skills, writing and creator tools, archived Mojo libraries, and a few things built for fun.
